System Overview

Presidio Rust is a high-performance PII (Personally Identifiable Information) detection and anonymization library ported from Python to Rust. It leverages Rust's safety guarantees and performance characteristics to provide a production-ready solution for data privacy.

6 Core Crates
5 Built-in Recognizers
40+ Entity Types
6 Anonymization Operators

Key Features

  • ✅ Context-Aware Detection: Uses surrounding text to boost confidence scores
  • ✅ Multi-Language Support: Supports 11 languages out of the box
  • ✅ Validation: Checksums (Luhn) and format validation for accuracy
  • ✅ Extensible: Plugin system for custom recognizers and operators
  • ✅ Thread-Safe: Designed for concurrent processing
  • ✅ Zero-Cost Abstractions: Performance without compromise

Data Flow Process

Input Text Reception

The system receives raw text containing potential PII through the AnalyzerEngine.

NLP Processing (Optional)

If an NLP engine is configured, the text is processed to extract linguistic features like tokens, lemmas, POS tags, and named entities.

Recognizer Selection

The RecognizerRegistry returns all recognizers that support the specified language and entity types.

Pattern Matching

Each recognizer runs its detection logic (regex patterns, validation, etc.) and returns potential matches with confidence scores.

Context Enhancement

Scores are enhanced based on surrounding context words. For example, "email" near an email address boosts confidence.

Deduplication & Filtering

Overlapping and duplicate results are removed, keeping only the highest-scored detections. Results below the score threshold are filtered out.

Anonymization (Optional)

Detected entities are passed to the AnonymizerEngine which applies operators (Replace, Redact, Mask, Hash, Encrypt) to transform the PII.

Result Return

The final results (analysis or anonymized text) are returned to the caller.
